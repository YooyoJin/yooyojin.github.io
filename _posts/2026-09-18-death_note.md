兄弟们，缩写给我往好的缩啊，缩得跟暗号似的。加个注释吧！我他妈以为自己在破译密码呢。

不加注释还用中文缩写，如同乐高没说明书，外语片没字幕，老马没冯🙄

## 1. 通用

- CFG/Config/配置
- BUF/Buffer/缓冲区
- LEN/Length/长度
- PTR/Pointer/指针
- CTX/Context/上下文
- HDL/Handle/句柄
- INIT/Initialize/初始化
- DEINIT/Deinitialize/反初始化
- CB/Callback/回调
- EVT/Event/事件
- MSG/Message/消息
- REQ/Request/请求
- RES/Response/响应
- RET/Return/返回
- TMP/Temp/临时
- IDX/Index/索引
- CNT/Count/计数
- MAX/Maximum/最大值
- MIN/Minimum/最小值
- SRC/Source/源
- DEST/Destination/目标
- ARG/Argument/参数
- PARAM/Parameter/参数
- HMI/Human Machine Interface/人机界面
- MGR/Manager/管理器

## 2. PID

- PID/Proportional-Integral-Derivative/比例积分微分
- SV/Set Value/设定值
- PV/Process Value/实际值
- FB/Feedback/反馈
- FF/Feed Forward/前馈
- PREV/previous/前一个
- PLS/Pulse/脉冲

## 3. 通信

- ACK/Acknowledgment/确认应答
- SYN/Synchronize/同步

## 4. 驱动
- IRQ/Interrupt Request/中断请求
- ISR/Interrupt Service Routine/中断服务程序
- DMA/Direct Memory Access/直接内存访问
- GPIO/General Purpose Input Output/通用输入输出
- ADC/Analog-to-Digital Converter/模数转换器
- PWM/Pulse Width Modulation/脉冲宽度调制
- UART/Universal Asynchronous Receiver/通用异步收发器
- SPI/Serial Peripheral Interface/串行外设接口
- I2C/Inter-Integrated Circuit/集成电路总线
